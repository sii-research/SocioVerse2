# 少数人说话，多数人跟随：混合 LLM–ABM 范式在社会运动舆论动态上的真值检验

## 摘要

社会运动爆发后的舆论演化，长期缺少一种既能生成话语内容、又能承载人群规模的模拟范式：纯 LLM 模拟在社交媒体所需的规模上代价过高，纯规则的舆论动力学模型则生成不出意见领袖实际说了什么。混合范式的做法是分工——少量"核心用户"由 LLM 驱动（真实画像、个人记忆、关注关系），海量"普通用户"由经典舆论动力学规则驱动，两侧通过镜像机制双向耦合。本文报告该范式在 Roe v. Wade 推翻事件上的一次真值检验：14 轮逐轮对照同期真实 Twitter 群体情绪，形状相关达 0.783（原文对该配置公布 0.758，差异来自数字化误差）。同一评测在三个社会运动场景上一致成立：混合范式的轨迹相关为 MeToo 0.724、Roe 0.758、BLM 0.605，而各场景最佳纯规则基线仅为 0.509、0.475、0.393；绝对水平偏差 ΔBias 0.009，同样优于纯规则的 0.033。个体层的单轮回复实验显示 LLM 核心用户复现真实用户立场的准确率为 0.943，内容语义相似度 0.809，说明群体层的吻合并非个体层误差互相抵消的巧合。我们同时定位了该范式最明确的失配：第 9 轮真实舆论出现回落而模拟只是走平，累计相关由 0.847 滑至 0.703。

## 1 引言

一起触发性事件之后，社交媒体上的舆论会怎么走？这个问题的实证材料并不稀缺——真实的情绪时间序列可以被观测——真正稀缺的是能和它对上话的模拟范式。

困难是结构性的。要让模拟产生可解释的话语，就得让 agent 真的写出内容，而这在社交媒体所需的人群规模上代价过高；要承载规模，就得退回规则驱动的舆论动力学模型，但规则 agent 只有一个态度标量，生成不出意见领袖的论证、修辞与议程设置。近年 LLM 驱动 ABM 的兴起提供了新的组合空间 [gao2024large]，但也随之带来一个更尖锐的问题：这些模拟究竟有没有被验证过 [larooij2025validation]。

本文检验的是一个具体的组合方案：把话语交给少量 LLM 核心用户，把规模交给大量规则普通用户，二者通过镜像机制耦合 [mou2024unveiling]。检验方式是逐轮对照真实观测到的群体情绪轨迹。

## 2 相关工作

**混合 LLM–规则的舆论动力学。** 领域综述把 LLM 与 ABM 的结合分为若干支 [gao2024large]，本文所检验的方案属于"两类 agent 并存并互相耦合"一支。最接近的同类做法是把舆论动力学方程直接融入 LLM agent 的输入以做预测 [yao2025social]——它把规则写进提示，本文的方案让两类 agent 各自演化再互相覆写，二者构成同一问题的两种耦合设计，可直接对照哪种更稳。在扩散侧，LLM 增强的影响力传播 ABM 报告了"扩散会把话题收窄"的现象 [zhang2025llmaidsim]，与本文中段模拟情绪系统性偏高、态度多样性收敛的观察互为旁证。另有工作量化了 LLM 参与者本身如何改变群体意见动态 [li2023quantifying]，提示核心用户比例是一个会影响整体轨迹的结构参数。

**社交媒体数字孪生环境。** 本文所用的环境层（时间线、关注图可见性、通知收件箱、按轮注入的真实新闻）与 Twitter 式 LLM 数字孪生的构造同类 [rossetti2024y]，后者可作为环境侧的参照实现。

**验证问题。** 对生成式社会模拟最有力的批评并非"跑不出结果"，而是**没有真值可对**——大量工作停在"结果看起来合理"[larooij2025validation]。本文的全部设计都是对这一条的直接回应：逐轮对照真实情绪、报出形状相关与绝对偏差、并公开失配点。个体层的立场测量则依赖立场检测方法 [lan2024stance]。

## 3 方法

**人群 P（两层）。** 核心用户为 LLM agent，由真实 Twitter 用户画像构建，携带个人记忆、历史发文与关注关系；普通用户为 ABM agent，其态度按选定的经典模型更新（有界信心、Hegselmann–Krause、Lorenz、相对一致、社会判断，逐场景可换）。

**环境 E。** Twitter 式信息环境：每个 agent 每轮可见时间线上最近的 k 条，可见性由关注图决定，另有通知收件箱；真实新闻按轮注入。Roe 场景注入两次——第 0 轮的最高法院推翻判决，第 10–11 轮的华盛顿特区抗议与逮捕。

**行为函数 f（混合）。** LLM-f 服务核心用户（画像 + 时间线 + 记忆 → 发文/转发/回复/点赞/不动作），rule-f 服务普通用户（按所选模型更新态度）。二者通过**镜像机制**耦合：ABM 侧为每个 LLM agent 维护一份镜像，每轮用该 LLM agent 实际发文的情感覆写其态度值，于是话语能真正带动人群，人群反过来构成 LLM agent 看到的时间线。

**指标。** 每轮记录 `sim_sentiment` 与 `gt_sentiment`（两条序列各自 min–max 归一化到 [0,1]，因绝对量程不重叠且评估针对轨迹形状）、`abs_gap` 与累计 Pearson 相关 `cum_corr`。绝对水平的吻合另以 ΔBias 报告。

## 4 结果

**逐轮对照。** 图 1 给出模拟与真实两条曲线，灰带为真实新闻注入窗。

![14 轮模拟舆论与真实 Twitter 舆论的逐轮对照，灰带为新闻注入窗](figures/trajectory_vs_truth.png)

14 轮的形状相关为 0.783。两次新闻注入都得到响应：第 0 轮的判决推翻启动上行，第 10–11 轮的抗议与逮捕后曲线再次抬升，末轮两条曲线收敛，差距仅 0.018。

模拟侧整体**跑在真值前面**：第 5–11 轮系统性偏高，最大单轮差距 0.446 出现在第 11 轮。最值得注意的是第 9 轮——真实舆论明显回落，模拟只是走平，累计相关由第 8 轮的 0.847 滑到第 11 轮的 0.703，随后才回升到 0.783。这是本次检验中最清晰的一处失配，指向核心用户对事件的反应比真实人群更快也更持续。

**混合优于纯规则，三场景一致。** 图 2 给出三个社会运动场景下混合范式与最佳纯规则基线的轨迹相关。

![三个社会运动场景下混合范式与最佳纯 ABM 基线的轨迹相关对比](figures/hybrid_vs_abm.png)

MeToo 0.509→0.724，Roe 0.475→0.758，BLM 0.393→0.605，提升幅度 0.21–0.28，无一场景例外，且不是由某一个场景撑起来的。绝对水平同样改善：ΔBias 由纯规则的 0.033 降到 0.009。适配的经典模型逐场景不同——Roe 是 Lorenz，MeToo 与 BLM 是相对一致——这使"哪种经典机制最适合配合 LLM 核心用户"成为可系统消融的问题。

**个体层的对齐。** 图 3 给出核心用户与其真实对应者的单轮回复对齐度。

![LLM 核心用户与真实用户在立场、内容与行为类型上的对齐度](figures/micro_alignment.png)

立场准确率 0.943，内容语义相似度 0.809，内容准确率 0.642，行为类型准确率 0.667。三个场景的立场准确率均不低于 0.899。这一层是必要的：若个体层是乱猜，群体层的吻合就只能是误差互相抵消的巧合，换个场景会立刻失效。

## 5 讨论

三场景一致的提升支持一个结论：**话语内容对复现集体舆论轨迹是有信息量的，而这正是纯态度标量模型缺失的部分**。混合范式的价值不在于"用了 LLM"，而在于它把生成能力放在了真正需要生成的位置——少数带动议程的账号——而把其余人群交给便宜且稳定的规则动力学。

**边界需要写清楚。** 其一，本文展示的轨迹是**已发表运行的导入**，由脚本从技术报告图表源码逐点提取并回读校验，不是在本工作台内重新执行的模拟；工作台内另做过一版 20 agent、4 步的真实 LLM 移植验证，其结果（群体偏移 −0.2223→−0.1590，多样性 0.3216→0.1908，核心用户上行而普通用户几乎不动）单独记录，不与本文轨迹混用。其二，**两条序列均为归一化后的形状比较**，绝对水平的吻合由 ΔBias 单独承担。其三，相关系数有两个口径——数字化重算 0.783 与原文公布 0.758——本文凡引用原文结论时用后者。其四，**没有逐人面板**：原文只公开聚合轨迹，个体层证据是上述对齐指标而非逐人序列。其五，环比方向仅命中 7/13，说明吻合主要来自趋势段而非逐轮抖动；14 轮是小样本，不宜过度解读。

更根本的一条来自验证问题本身 [larooij2025validation]：一次场景上的高相关不等于范式被验证。本文能主张的是"在三个事件驱动场景上一致优于最佳纯规则基线"，不能主张"该范式可外推到任意事件类型"。

**下一步**最有价值的是第 9 轮那次失配：真实舆论掉、模拟没掉。去查那一轮真实世界发生了什么、当前信息环境里缺了哪一条，是把"拟合得不错"变成"知道为什么拟合不上"的入口，也是这类模拟真正的用途所在。
